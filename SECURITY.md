# Security

starwire is a static list and website with no accounts, servers or stored personal data.

If you find a security problem, such as a listed repo that is malicious, or a bug in the site that could harm visitors, report it privately through [GitHub's private reporting](https://github.com/boffti/starwire/security/advisories/new). Please don't open a public issue for it.

Malicious or compromised repos are removed from the list on the next update.
